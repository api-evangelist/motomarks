# Motomarks

A car-manufacturer logo API and image CDN delivering badge, wordmark, and full-logo assets plus structured brand data for 420+ automotive brands. Offers a REST/JSON API, a token-authenticated image CDN, a hosted MCP server, an llms.txt, and published agent skills.

- **Base URL:** https://api.motomarks.io

- **Confidence:** 95/100

## APIs

- **JSON API** — Bearer-authenticated REST/JSON API for listing brands and retrieving full brand detail including color palettes, website, social links, and metadata. (`https://api.motomarks.io`)
- **Image CDN** — Token-authenticated global image CDN delivering car logos in full, badge, and wordmark variants across multiple sizes and formats. (`https://motomarks.io/img`)
- **MCP Server** — Hosted streamable-HTTP MCP server exposing read-only brand tools, account tools, resources, and prompts. Auth via OAuth 2.1 or Bearer secret key. Registry name io.motomarks/mcp. (`https://motomarks.io/api/mcp`)

> No formal machine-readable API contract (OpenAPI/AsyncAPI/GraphQL/Postman) is published; the strongest machine-readable artifacts are agent-native. The GitHub repo (github.com/motomarks/motomarks-mcp) hosts a skill at skills/find-brand-logo, .claude-plugin, .cursor-plugin, gemini-extension.json, .mcp.json, and server.json. A local MCP proxy option exists via 'npx -y mcp-remote https://motomarks.io/api/mcp' but the primary MCP endpoint is hosted at https://motomarks.io/api/mcp.
