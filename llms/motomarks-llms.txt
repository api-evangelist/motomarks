# Motomarks

> Every car logo, one simple API. Production-ready automotive logos and structured brand data for developers.

## About

Motomarks provides an image CDN and JSON API for automotive products. Published assets are available as full logos, badges, and wordmarks in PNG and WebP, with five preset sizes and two aspect behaviors.

## Logo Pages

Every published brand has a stable logo page at https://motomarks.io/logos/{brand-slug} (for example https://motomarks.io/logos/porsche).

Each logo page includes:
- The current manufacturer mark and available variants (full, badge, wordmark)
- Production CDN URL pattern: https://motomarks.io/img/{brand-slug}
- Brand facts (founded year, country, company, colors)
- How to add the logo in an app (CDN parameters and publishable key)
- History, logo changes, design notes, and FAQs when enrichment exists
- Related manufacturer pages for internal navigation

Logos remain the property of their owners. Motomarks delivers published assets and structured data; it does not grant trademark rights.

## API

- Image CDN: https://motomarks.io/img/{brand-slug}
- Parameters: type (full|badge|wordmark), size (xs|sm|md|lg|xl), format (png|webp), aspect (square|height)
- JSON API: https://api.motomarks.io/brands
- MCP server: https://motomarks.io/api/mcp (OAuth or secret-key auth; search brands, get brand data, build CDN URLs)
- Current coverage: https://motomarks.io/logos
- Free tier: 1,000 requests/day (attribution link required)
